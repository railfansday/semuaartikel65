📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

This is part of a forthcoming enhancement that adds fresh high-visibility options.

Google Maps is getting new high-visibility options, according to a report by Android Authority. This should make the maps easier to see under certain real-world lighting conditions, due to updated color palettes in both the light and dark modes.

Industry observers note that for instance, the dark mode looks darker than ever before. It features blacker backgrounds and a purple navigation route. Bodies of water and green spaces are both darker, making them easier to identify at a glance.

The updated light mode also features some noticeable changes. Green spaces are darker and a bit more muted. Off-white and beige sections have changed to different shades of gray, while the blue location indicator has turned purple. The end result is a slightly more subdued look.

Recent findings suggest that beyond latest color palettes, the navigation experience looks unchanged. It still offers turn-by-turn direction indicators and the bottom information panel remains the same across the two new styles.

These settings aren't publicly available yet. Android Authority managed to enable them via the latest Google Maps version, which lets users swap between the standard old-school palette and these fresh high-visibility options. We don't know when the update will go live. Engadget has reached out to Google to ask about a timeframe and will update this post when we hear back.

Recent findings suggest that this is just the latest nifty feature coming to Google Maps. The platform recently introduced 3D navigation maps and is stuffing chatbot functionality just about everywhere.
