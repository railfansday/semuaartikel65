iPadOS 27.3 is at the moment available in beta, and it introduces a new iPad setting for app windowing that I instantly turned on. Here are the details.

I use the iPad Pro as my primary computer, and for the most part have found Apple’s software changes in iPadOS 26 and 27 to be great upgrades.

But with the powerful new windowing capabilities, there have definitely been some quirks that need refining. One of them involves resizing windows with the traffic light controls in the top-left corner.

It has been revealed that for example, in iPadOS 27 the controls move locations and even disappear depending on the size of the window. It can be pretty frustrating.

According to recent reports, I need to just get better about learning keyboard shortcuts for window controls. But in the meantime, iPadOS 27.3 adds a new optional setting that I instantly turned on and have been loving.

Inside Settings ⇾ Multitasking & Gestures, if you have ‘Windowed Apps’ enabled you’ll see a upcoming option below it: ‘Double-tap Top of Window to Zoom’.

If you use your iPad mostly with touch input, or simply haven’t used keyboard shortcuts enough to remember them, this latest setting is a great way to quickly resize windows.

Industry observers note that when the setting is enabled, two taps (or a double-click with the trackpad) will zoom the window to take up the full screen. Then you can double-tap again to revert it to its previous size.

I generally keep my app windows in specific size setups, but regularly find myself wanting to go fullscreen temporarily. The new setting provides a convenient way to do that quickly without needing the traffic light controls or my keyboard, and is a welcome refinement to iPadOS windowing.
